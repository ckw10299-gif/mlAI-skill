# 游戏买量竞品分析

把投放情报和逐条素材证据转成可汇报、可复核、可复用的买量分析。先理解用户要采集、分析还是修订，避免把局部任务扩成完整重做。

## 工作范围

- **完整分析**：按下述流程执行，已有可靠数据与归档直接复用。
- **已有素材分析**：从核对与观看开始，不要求重配MCP、重新采集或提供自有产品brief。
- **修订分析**：回查相关原素材，同步受影响的逐条行、阶段说明、总览、对比和阶段图；保留无关内容与用户改动。
- **排版或媒体排查**：只处理指定格式、链接、权限、媒体或性能问题，不重解释全部创意。

## 证据与判断

1. 每张图片实际看，每条视频完整看。关键帧、ASR、字幕用于定位和复核，不能替代完整观看；媒体不可读时说明缺口，不根据文件名补写。
2. 分开写画面事实、广告宣称和分析推断。无效果数据不编CTR、CPA、ROI，也不把使用排名或高峰当转化证明。
3. 产品本体、广告演示和获客入口分开。fake/副玩法、IP、AI与KOL仍可有获客价值，不能因偏离本体就排除，也不能据此宣称正式功能或合作。
4. KOL用署名、字幕、口播和用户明确提供的信息识别，不凭无文字人脸猜身份；检查A、B口播、包框、角色化、福利与尾段。
5. 阶段主线可以交叠；区分首次试探、样本主导和长期复用。图片与视频可能不同步，不套统一发展路径。

## 执行流程与按需资料

### 1. 输入与采集

阅读 [任务与采集](references/workflow.md)。确认产品/版本、截止日、阶段范围、素材数、排序、媒体范围、交付位置和已有文件保护范围。输入见 [任务卡](assets/task-brief.md)。

先检查现成数据源；需要时才配置用户级原生MCP，凭据放安全存储或环境变量，验证initialize与tools/list；不把Key写入项目、报告或仓库。

获取开投至截止日的真实趋势，以持续峰谷、放量/回落/长尾及新增节奏提出阶段，再回看素材校准。投放阶段与创意换轨不是一回事。采集按用户口径；未另指定时，可采用“阶段日期＋新增素材＋媒体不限＋最多计划使用，图片/视频各TOP10”，明确为采样而非效果评价。不足、候补与变体如实记录。

### 2. 归档与逐条买量拆解

阅读 [分析方法](references/analysis.md)。在获准目录新增归档，保存UID—短名—原件—预览—Sheet行—附件映射，保护其他已有文件。

顺序：**产品→阶段→图片→视频A+B→视频单B→各形式内按卖点分组→逐条分析**。同类放一组，不跨阶段混合。

- 图片逐张贴入并分析类型、内容、钩子、构图/卖点、转化、复用与优化，再总结阶段主导主题。
- 视频逐条填写短名、画面预览、完整视频、HOOK、衔接、B卖点、内容架构、转化、复用和优化。
- 单B名称正文≤10字；A+B用“xxx+xxx”，编号如“01 名称”。沿用用户命名与编号约定。
- 衔接看同人物、同物件、同任务、同能力或同顾虑；仅同题材不代表任务闭环。
- 阶段开头写主线、图片、A+B、单B、迭代逻辑：解释形式、内容、变化、保留项及可能服务的动机。

### 3. 总览与素材表交付

阅读 [报告与交付](references/report-and-delivery.md)。默认总览每产品四项：**产品定位、目标用户、推广节奏、素材分析**；结尾为产品对比、题材共同打法、可执行建议。用户指定结构优先。

复用既有总览。逐条分析一个产品一份素材表、阶段分Sheet，总览留摘要和阶段链接。不可为每条视频另建文档。

素材表列：素材名称｜画面预览｜视频预览｜图片内容/HOOK｜A+B衔接｜构图/B面核心卖点｜内容架构｜转化设计｜可复用点｜优化点。不适用填“—”，无效果数据不加虚构数据栏。

两类图分开：推广节奏贴真实ADX趋势；素材分析开头可加阶段图（每阶段一点、≤10字说明、对应阶段真实图/帧、匹配游戏风格）。相对/等距示意标明口径。

视频优先上传现有表格原生附件/预览并验证完整播放。先核验原生能力；不可用时再确认稳定链接等替代，不静默降级。共享盘路径不是在线视频URL，数据源直链可能过期。

### 4. 验收与修订

阅读 [案例与验收](references/cases-and-qa.md) 的清单；需要校准判断时再读匿名案例。

修改前备份。媒体表优先原行编辑，避免插删行列破坏图片锚点与附件。保留用户标题、编号、视图及无关排版。

局部词语/短句加粗或红字，不整格全红全粗。检查目录、空标题、缺图、裁切、标题跨页、表头孤悬与留白。删除汇报中无价值的ID、归档过程、自我辩解和重复数值；重要数据缺口仍如实说明。

发布前重新读云端结果，沿“总览→阶段Sheet→单条完整视频”实际验证。权限、登录拦截、失效链接和卡顿分别诊断。分享授权不扩大到其他文件，不因历史授权永久默认公开。

最终给交付入口、完成范围、关键结论、媒体/权限/保存验证及真实未解决项。只完成文案或尝试上传时，不宣称已经全部发布。
