# 匿名案例、常见误判与验收

按当前用户授权和范围使用；案例与历史默认值不构成未来任务的事实或权限。

## 20. 四款产品的案例结论与易错点

以下是匿名化的历史解释框架，不是所有丧尸产品的标准四步路径。

### 20.1 案例A

**卖点测试→人物主题延展→丧尸主题fake化→KOL放大。**

- 初期：囤货、房车、搜打撤、老奶等人物反差并行，测试安全感、变强、收益与角色兴趣。
- 第二阶段：老奶、外卖员等人物进入连续任务与成长系列；图片仍有大量房车/庇护所，不把所有形式写成同步转向。
- 第三阶段：克苏鲁、古神、古文明、病毒源头等深化丧尸题材想象，熟悉人物继续承担识别。
- 第四阶段：某KOL署名、口播、包框、Q版角色和电影花絮式AI入口，接既有搜打撤和强装反馈。
- 复核发现：第四阶段样本中多条复用同一KOL资产；KOL不只在A面，单B讲解中也存在。图片既有明确推荐，也有“大哥”主题延展，仍有非KOL老奶/克系内容。

易错：只写“剧情搜打撤”“人物口播”，遗漏具体KOL打法；只看封面错过B面署名；把整阶段每张图都归某KOL；把素材自称代言或真实花絮当已验证外部事实。

### 20.2 案例B

**恐怖氛围＋本体玩法→恐怖/fake双线→AI与副玩法扩展→末日/鬼新娘双主题小游戏模板。**

- 第一阶段：中式恐怖、鬼怪与背包合成、撤离规则结合，已有少量副玩法试探。
- 第二阶段：恐怖角色与玩法继续主题延展，同时大量测试挖矿、拼塔、城堡对轰；该阶段有多条此类副玩法表达。
- 第三阶段：AI关系冲突、弱强反转、夸张成长与副玩法更突出，获客入口更轻、更泛；背包教学没有完全消失。
- 第四阶段：末日守门与鬼新娘两条主题，主要用防守、清波次和技能成长承接；守门/融合类与鬼新娘类在本阶段占突出位置，另有AI生活和浮岛副玩法。

易错：把不像本体的广告一律排除，错过fake测试主线；把AI等同fake；把第三阶段全部判fake；把第四阶段10条全部判塔防；只分析主题，不分析“轻规则拓泛人群”。

### 20.3 案例C

**早期经典IP/泛游戏入口借势，贯穿A面变体＋数字门B面变体。**

- 第一阶段已出现GTA、植物大战僵尸、马里奥、单机封面/推荐合集等熟悉认知入口。
- A面反复更新群聊、评论、地铁、办公室、路人和真实性争论。
- B面反复更新数字门、人口、火力、奖励、敌人、地图与螺旋成长。
- 不同投放时间窗之间主要是配比、规模与元素变化，没有必要硬写成多次战略转型。
- 个别片内标其他游戏品牌，应保留识别，不用来证明目标产品的周年活动。

易错：早期经典IP都被当成无关图片；误写数字门到第二阶段才首次出现；把A面场景变化夸大成产品买量策略换轨。

### 20.4 案例D

**时间推进＋版本/赛季主题化，再以能力演示、攻略和回归便利承接。**

- 早期“活下去”：丧尸爆发、救援、伙伴与家园，先建立末日世界。
- 半感染者：以新身份、统一视觉和能力主题化。
- 海上生存：用新空间、新危机、运输与资源任务拓世界边界。
- 巨型感染、极夜、心蚀、引擎换新、新种族等继续提供变化。
- 一轮主题可以拆成：海报/奇观吸引→能力/场景说明→职业攻略、任务、减负和福利承接。

易错：只写长期经营与回归减负，遗漏世界主题；把攻略增多写成主题结束；把ADX阶段直接对应一个官方赛季；把大怪仅当零散猎奇，没有继续看设定和人物关系。


## 21. 常见问题与处理清单

| 问题 | 正确处理 |
|---|---|
| 文字很多，结论很少 | 删过程口径、重复数值和套话，每段保留判断、证据、含义 |
| 参考图里有CTR等数据 | 无真实数据就不填，只参考结构和形式 |
| 图片只有类型汇总 | 补每阶段每张原图和逐张分析，再写阶段主导主题 |
| 视频都混在一起分类 | 先按阶段，再分A+B/单B，再按卖点分类 |
| 小标题不醒目/目录缺失 | 用真实标题层级；检查四产品、综合分析、全部阶段和空标题 |
| 标题或表格跨页割裂 | 标题与后文保持，重复表头或调整行高；实际检查分页 |
| 趋势图只有来源字，图没显示 | 检查图片是否真正插入和成功加载，不以接口成功代替可见 |
| 重点整格加粗全红 | 使用局部富文本，仅强调关键字和短句 |
| ADX视频链接打开失效 | 检查时效，优先原生上传，不把短链用于长期汇报 |
| 共享盘地址点击不播放 | 将其当归档路径，另完成原生上传或经确认的稳定媒体方案 |
| 每视频多建一份文档 | 停止扩散，复用产品表；授权范围内清理冗余 |
| 不像本体的素材被全部排除 | 分析其fake/IP/泛入口作用，同时保留产品归属边界 |
| 只用阶段高峰解释“有效” | 高峰说明投放强度，效果需另有业务数据 |
| 用户修正观点后只改一句话 | 回到原素材复核，同步逐条、阶段、总览、综合表和图 |


## 22. 最终验收标准

### A. 采集与归档

- [ ] 产品、平台、版本正确；起止日期与分析截止日明确。
- [ ] 阶段来自完整趋势，日期连续，指定阶段没有误扩。
- [ ] 新增素材、最多计划使用、媒体不限、图片/视频分别筛选均正确。
- [ ] 数量不足、候补、重复、变体有据可查，没有暗中改口径。
- [ ] 共享盘目标路径正确，其他已有文件未被操作。
- [ ] 文件可打开，短名合规，编号与台账/分析行一致。

### B. 内容

- [ ] 每张图片贴入并分析；每条视频完整观看并逐条分析。
- [ ] 阶段内先图片，再A+B和单B，卖点分类清楚。
- [ ] HOOK、衔接、B面卖点、内容架构、转化、复用、优化完整且具体。
- [ ] 无虚构数据、无未经观看的情节、无凭脸猜人。
- [ ] KOL/IP/AI/fake/本体玩法多轴区分；广告宣称与事实分开。
- [ ] 阶段说明回答形式、内容、变化、保留项和获客作用。
- [ ] 总览、素材表、综合分析、节奏图的判断一致。

### C. 报告与媒体

- [ ] 总览每产品四项小标题与综合分析完整，阶段目录齐全，无空标题。
- [ ] ADX真实趋势可见，阶段图文案短、素材对应、风格匹配。
- [ ] 一个产品一个素材表，阶段分Sheet；总览链接跳到正确位置。
- [ ] 视频真实上传或使用确认过的可用方案，没有临时直链充当长期入口。
- [ ] 以目标读者权限测试总览、子表、图片与完整视频。
- [ ] 标题、表头、图片、单元格没有裁切或异常跨页，留白与层级适合汇报。
- [ ] 关键词仅局部加粗/标红，不整格强调。
- [ ] 云端重新读取确认保存，抽查实际页面，必要时核对媒体哈希和附件映射。
- [ ] 无新增无必要文档，无遗留临时工具/认证信息，无误删正式资料。
